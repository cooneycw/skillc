- **skill-usage records and a hook that writes them** (#719). A new `skill-usage` record kind, one JSON object per line of an append-only `*usage.jsonl` log, enforced by four `check-records` rules proven by `selftest` (`skill-usage-envelope`, `-fields`, `-privacy`, `-pairing`): no home path, email or extra field; `"UNKNOWN"` never omitted; no orphan `end`. `skillc usage hook` is a fail-open Claude Code hook (PreToolUse `Skill`, UserPromptSubmit `/<skill>` by exact lookup, Stop/SessionEnd) writing to the main checkout's `.skillc/usage.jsonl` through `git-common-dir`; `skillc usage end` declares an outcome; `skillc usage report` counts by skill and digest. Registration is by hand (`docs/skill-usage-hook.md`).
