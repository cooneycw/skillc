- **The skill-usage log is written only when git says it is ignored** (#722). The writer used to look for a `*` or `usage.jsonl` line in `.skillc/.gitignore`, so a later `!usage.jsonl` left the private log committable while the check passed. It now asks `git check-ignore` on every path. If git says the log is not ignored, the writer appends a final `/usage.jsonl` and asks again. A log git still will not ignore (a tracked one), or a check that errors, times out or finds no git, is not written: both commands exit 0 and print the refusal.
