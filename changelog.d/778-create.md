- **`skillc charter create` and the `/charter-create` skill** (#778, part B). `/charter-create` composes a skill's charter WITH the owner. It walks the owner through every suggestion `charter evidence` found (accept, edit or drop), then the intent, each must-always, each must-never and authority. For every must-never it asks for the tempting shortcut a capable model would take. `charter create` turns those answers into a CHARTER.md plus a trap-task stub per clause at `evals/trap-tasks/<contract>/<clause>/{bad,good}/`, so `clause-backed` and `negative-backed` pass from creation. A stub has no grader, so round 3 refuses it until #736 fills it. `create` refuses, writing nothing, on an unanswered suggestion, a never or authority rule with no shortcut, or an approval the owner did not give with a date. It stamps `approved` only on intent and authority. It then runs the real contracts rules and rolls everything back on any error. It never edits the skill and never commits. No model call.
