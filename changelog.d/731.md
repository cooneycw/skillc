- **`skillc inspect`: four precise false verdicts fixed** (#731). A file inside a control's
  `bad/`, `good/` or `targets/` is no longer credited as a rule's enforcer (bucket A). A
  flag belongs to its segment's command - the first word after any interpreter or shell
  keyword - so a later file argument no longer takes it, `$(...)` restores the outer
  command when it closes (including `"$(pwd)"` in one token), and a separator trailing a
  flag (`--bad;`) still checks that flag. `copied-passage` anchors on rare windows and
  extends backward, so a repetitive prefix is measured whole in either document order;
  only purely repetitive text falls back to a bounded search, and that finding and the
  report summary say "bounded estimate".
  Command text (code spans and fenced lines, never prose) is now tokenised with stdlib
  `shlex`, so quoted arguments stay whole and only unquoted separators split commands;
  wrapper option values (`sudo -u|--user`, `env -u|--unset`, a `$(...)` value) never
  take the command position, and a flag after a non-command path is counted rather
  than dropped.
