- **A project-gate witness (`project-check`)** (#508, the agent-chooses design from #287) witnesses the agent's own `make check`.
  - A root-owned `make` shim, first on the agent's PATH only, forwards `make`, `make check` or `make <declared stages>` to the controller.
  - The controller runs each declared stage itself, one exec per stage, stopping at the first failure, and records the exit codes it received. It replies with make's own bytes and exit status, which committed real-make goldens pin.
  - Any other `make` call runs the real make and is logged as subject-reported, never evidence.
  - A Makefile that drifted from its declared digest is run by the real make with no stage truth.
  - Controller gate execs never carry the shim directory. One gate witness per attempt owns every gate exec.
