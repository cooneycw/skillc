- **leak-check no longer trusts a partial account listing for the encoded placeholder exemption** (#730). On an NSS/SSSD host with enumeration off, `getpwall()` can omit a directory account such as `user.operator` that lookup by name still finds, and its encoded home (`-home-user-operator-...`) passed as the redacted placeholder. Each encoded placeholder match is now probed by name (every `-`/`.`/`_` de-encoding of up to three following segments), and the scanning account is checked by uid, so neither can hide behind the exemption.
