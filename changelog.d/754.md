- **`skillc gauntlet run <collection> <skill>`: the skill-gauntlet engine, part 1** (#754).
  Runs rounds 0-2 in order by calling the existing commands (`usage report`, `charter
  draft` or `contracts`, `charter overlap`, `inspect`) and reading only their verdicts.
  Prints one verdict per round and one `NEXT:` line. Rounds 3-5 read `NOT BUILT`, so it
  never exits 0 yet and never gives a keep/trim/retire verdict. Writes `GAUNTLET.json`
  beside the skill's charter, deterministic and only on change, and never commits it.
  Adds the `/skill-gauntlet` skill (`.claude/skills/skill-gauntlet/`).
