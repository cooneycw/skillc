- **`skillc charter evidence <collection> <skill> --out FILE`** (#778, part A of `/charter-create`). It gathers every existing piece of a skill's charter before the owner is asked anything, and writes each as a cited suggestion for the owner to accept, edit or drop. Sources: discussions, issues and PRs named with `--ref` (read-only GraphQL queries through `gh`; a name search only with `--search`), an existing CHARTER.md or draft and its git history, the skill text and `--doc` specs, usage records, and test files that name the skill. Only items under charter-shaped headings (Job, Intent, Purpose, Must always, Must never, Authority) are taken from GitHub, never prose or fenced examples. Every item is labelled observational, and quotes stay under 40 words. Every source reports `examined`, `none found` or `not examined: <reason>`, so a missing `gh` is never silently empty. No model call.
