- **`skillc inspect`: the two #741 pass-3 false negatives closed** (#745). A fully quoted
  option (`"--absent=x y"`) is checked against its owner like `--absent="x y"`, which
  fixes a regression against #731's code. Flags inside or after an `env -S` /
  `--split-string` value are now counted in `flags_after_a_non_command_path` as not
  examined, never checked and never silent; the value's paths are still checked. env's
  own argv rules are not emulated, which the spec states as a limit.
