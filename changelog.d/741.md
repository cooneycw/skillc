- **`skillc inspect`: five false negatives fixed** (#741). Command text is split with
  exactly stdlib `shlex`'s posix word boundaries, plus whether each operator, `$(` and
  `)` was unquoted. So a quoted `";"` is an argument, a quoted `"$(pwd)"` is
  self-contained, and a quoted string that closes a substitution still closes it. A
  quoted multi-word string has its paths checked before any substitution logic.
  `$(...)` saves and restores the whole command state, so an inner `;` cannot clear an
  outer `sudo`. `env -S` / `--split-string` values are read as command text, with their
  flags counted as unowned. `copied-passage` pools a repetitive window's alignments
  with the anchored ones before anything is consumed, so a rare anchor no longer
  starves a longer match; a pair that hits the 512-extension cap is labelled a bounded
  estimate.
