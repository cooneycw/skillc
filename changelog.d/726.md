- **Skill-gauntlet round 1, part A: `skillc charter draft` and `skillc charter confirm`** (#726). `draft` proposes a `CHARTER.md` in #720's format from a skill's text (its MUST/ALWAYS/NEVER sentences and description) and its `skill-usage` records (#719). It sorts each duty into #718's columns: observed-and-stated, stated-not-observed, observed-not-stated, and `unknown`. `unknown` is used whenever no complete-coverage record for the skill could have shown the duty: no log, an empty or unreadable log, or only partial or unsupported coverage. Drafting makes no model call, never approves, and exits 3 with "nothing to draft from" rather than printing an empty charter. `confirm` applies the owner's own answers file (accept, edit, drop, forbid), refuses without one, and stamps `approved` only on intent and authority clauses. `skillc contracts` now reads a slash command's charter at `charters/<ns>/<cmd>/CHARTER.md`, whose required `subject:` must name an existing command file (owner decision 2026-11-15, claude-power-pack#1838). The overlap view is part B. Spec: `docs/specs/charter-round1.md`.
- **Skill-gauntlet round 1, part B: `skillc charter overlap`** (#726). Compares every duty across a collection's charters by meaning, behind a `DutyComparator` seam, and proposes `shared` (two charters claim one duty), `shadowed` (a skill is only observed doing what another charter claims) and `orphan` (observed behaviour no charter states). Overlaps are proposals for the owner, never findings. Each pair is judged over replicates; any disagreement is `UNKNOWN`. With no comparator it exits 3, "not examined", and reports no counts. `--verdicts FILE` reads recorded verdicts. The planted controls (`evals/subjects/overlap-controls`) separate meaning from wording, and a word-overlap comparator gets both wrong. No model call is made: the live run is sized, not run (#747).
