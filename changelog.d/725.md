- **`skillc inspect`: skill-gauntlet round 2, decay rules and A/B/C/D sorting** (#725). Four
  collection-level rules, each with committed controls in `skillc selftest`:
  `dangling-reference` (error: a path, link or script flag that the text names into the
  collection does not exist), `expired-marker` (an `until #N` / `expires-with: #N` rule
  whose issue has closed; UNKNOWN, never fine, without `gh` or the network),
  `copied-passage` (40+ identical words shared by two documents) and `emphasis-density`.
  `skillc inspect <collection>` runs them, folds in an optional `skillc exposure` report,
  and sorts each finding into claude-power-pack discussion #1830's groups. A counts only
  when the named enforcer's known-bad case exists, D is a closed temporary rule, B and C
  are never guessed, and everything else is UNSORTED with a reason. Each A or D item names
  the tests that pin its document. A hard error STOPS the run; an empty collection is
  "nothing inspected". On claude-power-pack at `d5ef0a66` it re-finds all twelve closed
  `until #N` rules from #1830 Part 2; see `docs/measurements/inspect/`.
