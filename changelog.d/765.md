- **The /skill-gauntlet launcher runs only this checkout's own skillc** (#765). Its import check now requires the imported `skillc/gauntlet.py` and `skillc/cli.py` to be exactly the checkout's files, compared by real path. A non-editable copy in the checkout's own `.venv` passed the old "somewhere under the checkout" check, and it ran code that a `git pull` never updates. It is now refused with the cannot-find line (exit 2), naming each module relative to the checkout. A checkout reached through a symlinked path, which the old check refused, now runs.
