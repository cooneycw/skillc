- **The clutter census matches a delivered file the way git sees it** (#727). A workspace file is delivered when it has the delivered blob's bytes and its owner-execute bit. The other permission bits come from the umask, which git cannot record. Under umask 0002 a correctly delivered file (0o664) used to read as clutter, which gave a false `NOT_CLEAN` and failed 5 tests on a group-writable host. Different bytes, a changed execute bit, or a setuid, setgid or sticky bit still read as clutter. Captures and every other comparison keep exact modes, and the capture schema is unchanged. The blind spot is named in `docs/specs/evaluation-facility/clutter.md`: a delivered file that is group- or world-writable reads as delivered.
