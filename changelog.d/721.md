- **The skill-usage writer no longer follows symlinks** (#721). `skillc usage hook` and `skillc usage end` refuse a symlinked `.skillc/`, `.skillc/.gitignore` or `.skillc/usage.jsonl` and write nothing, so a cloned repository cannot make the unprompted hook append to a file outside it. Every open goes through a `.skillc/` directory descriptor with `O_NOFOLLOW`; both commands still exit 0 and print the refusal.
