- **The default trigger-socket directory is per uid** (#817). A second host identity (for example a root controller after the CI lane's service account) used to meet the first identity's `skillc-trigger` directory and be refused. The default is now `skillc-trigger-<uid>` under the temp dir. The refusal of a foreign-owned, wrong-mode or non-directory path is unchanged, and now carries a closed reason class that the protocol run reports (`protocol-step-unavailable:TriggerDirRefused:<reason>`) without the path or uid.
