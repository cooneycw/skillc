- **`/skill-gauntlet` from any Claude Code session** (#763). `make install-skill`
  links `~/.claude/skills/skill-gauntlet` to this checkout's skill, so a `git
  pull` updates it everywhere; `make uninstall-skill` removes only that link. It
  refuses to replace a real directory or a foreign link, and from a linked
  worktree it links the main checkout. The skill calls a launcher
  (`scripts/gauntlet.sh`) that finds skillc from any working directory, and says
  `SKILL_GAUNTLET: cannot find a usable skillc` instead of giving a verdict when
  it cannot.
