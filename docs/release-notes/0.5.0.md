# skillc 0.5.0 - controlled evaluation workflows and retained evidence

0.5.0 adds workflow dependency profiles, qualified task fixtures, calibration
and uptake studies, controller-held observations, fixture services and retained
evidence export to the 0.4.0 hardening baseline. The static checker still proves
its 31 rule families discriminate. The
[tag-pinned changelog](https://github.com/cooneycw/skillc/blob/v0.5.0/CHANGELOG.md)
contains the detailed inventory.

## Delivered capability

- Profiles inventory declared workflow dependencies, preserve executable modes
  and select pinned runtime supplies. Agent egress is provider-only; separate
  grading uses network-none containment. The runtime-tool and mode repairs are
  delivered ([#343](https://github.com/cooneycw/skillc/issues/343),
  [#442](https://github.com/cooneycw/skillc/issues/442),
  [#538](https://github.com/cooneycw/skillc/issues/538), closed). Known profile
  closure limits remain under [#553](https://github.com/cooneycw/skillc/issues/553).
- Qualified fixtures exercise omitted tests, incomplete aggregate gates and
  clean-project versus must-act decisions through a controller-owned fixture
  service and gate witness. Their graders have wrong-candidate and broken-grader
  controls ([#270](https://github.com/cooneycw/skillc/issues/270),
  [#434](https://github.com/cooneycw/skillc/issues/434), closed).
- Calibration and uptake have retained live reports. The
  [two-arm calibration](https://github.com/cooneycw/skillc/blob/v0.5.0/evals/calibration-204/report.md)
  found both arms at ceiling, 4/4 each, without natural skill opening.
  [B/N/P calibration](https://github.com/cooneycw/skillc/blob/v0.5.0/evals/calibration-203/report.md)
  and its low-effort rerun also reached ceiling. Their nested-directory
  installation constraint is now documented beside the results. The
  [description uptake study](https://github.com/cooneycw/skillc/blob/v0.5.0/evals/uptake-study/README.md)
  measured a bounded selection effect ([#237](https://github.com/cooneycw/skillc/issues/237), closed).
- The bounded selection probe now has its detection-control and same-run retained
  transcript evidence ([#26](https://github.com/cooneycw/skillc/issues/26), closed).
  Original null observations and the unexercised overlap choice remain limits.
  New selection runs pin complete grader identities and store eligible verified
  results, while [#545](https://github.com/cooneycw/skillc/issues/545) remains open.
- `skillc retained-export` reproduces and hands off retained evidence without a
  new model run ([#556](https://github.com/cooneycw/skillc/issues/556), closed).
  The delivered handoff preserves unknown installation readiness and overall
  INCONCLUSIVE results. A task endpoint PASS does not become an overall PASS.

## Deliveries merged on October 28

- Description optimization preserves valid numeric zero when ranking candidates;
  missing scores, ties and incomplete screens keep their previous treatment
  ([#599](https://github.com/cooneycw/skillc/issues/599), closed;
  [PR #602](https://github.com/cooneycw/skillc/pull/602)).
- Older pinned CPP snapshots have revision-matched license notices alongside
  their copies, preserving frozen tree bytes and identities
  ([PR #603](https://github.com/cooneycw/skillc/pull/603)). This delivers the
  license slice of [#553](https://github.com/cooneycw/skillc/issues/553), which remains open.
- Clean built-wheel installation is now required by local and CI gates, with
  installed-rule, absent-controls and same-exit/different-findings sabotages.
  A failed structured comparison now fails the shell script
  ([PR #604](https://github.com/cooneycw/skillc/pull/604)).
- A timed-out Docker `run -d` gets one further daemon-response window before
  removal, preventing a late create from landing after a premature cleanup.
  Unconfirmed cleanup identifies the attempt for a later sweep. This failure
  path can take twice the original daemon bound
  ([#540](https://github.com/cooneycw/skillc/issues/540), closed;
  [PR #601](https://github.com/cooneycw/skillc/pull/601)). Interrupt and residue
  obligations remain under [#549](https://github.com/cooneycw/skillc/issues/549).
- Replay-tested stall samplers and attribution tooling retain ambiguous,
  unattributed and unassessed observations
  ([PR #605](https://github.com/cooneycw/skillc/pull/605)). Live diagnosis and
  its acceptance threshold remain tracked by open
  [#484](https://github.com/cooneycw/skillc/issues/484).
- Uptake reports separate not-run, unavailable and unknown dispositions from
  captured/inconclusive attempts whose selection is undecided. Existing
  classifier booleans and comparison statistics are preserved
  ([PR #606](https://github.com/cooneycw/skillc/pull/606)).
- New uptake, calibration and discrimination schedules reserve at least 16
  seconds per attempt beyond the agent limit, derived from 12 retained live
  attempts whose maximum observed non-agent time was 15.622 seconds.
  Twelve historical declarations retain their exception only through canonical
  whole-declaration digests; their JSON, approvals and reports are unchanged
  ([PR #607](https://github.com/cooneycw/skillc/pull/607)). The allowance is an
  observed minimum, not a worst-case bound. Both reporting and budget changes
  are partial deliveries of open [#546](https://github.com/cooneycw/skillc/issues/546).
- `skillc calibration-report <run_dir>` rebuilds an interrupted run's private
  report from its checkpoint and verified ledger without starting an agent.
  Launch-bound snapshots select the report; legacy runs require the original
  `--declaration`, checked against recorded pins and ledger identities.
  `--rehearse` explicitly recovers rehearsal accounting
  ([PR #610](https://github.com/cooneycw/skillc/pull/610), #546 item 6).
- CPU-attribution self-tests run after ordinary pytest workers exit and are
  reaped. Independent collection and exact report-union checks preserve the
  selected population, with committed missing, dropped and duplicate evidence
  controls ([PR #608](https://github.com/cooneycw/skillc/pull/608)). Broader
  timing work remains under open [#462](https://github.com/cooneycw/skillc/issues/462).
- Artifact qualification now shares that serial phase, after ordinary workers
  are reaped ([PR #611](https://github.com/cooneycw/skillc/pull/611)). The frozen
  evaluator bytes, five-second probe cap, 450-second whole deadline and explicit
  0.3-second slow control are preserved. Completeness controls require the exact
  qualifier consumer identities and passing outcomes in the manual proof.
- Native calibration and discrimination schedules stop before the next attempt
  after observing server-side tool use or successful egress outside the provider
  allowlist. Checkpoints retain the trigger and remaining not-run slots;
  recovery refuses inconsistent stop markers and does not claim an older run
  stopped when it continued ([PR #612](https://github.com/cooneycw/skillc/pull/612),
  #546 item 7). This live-path change is **not yet verified on a real daemon
  (host real_docker run pending)**.

## Evidence limits and open work

Container verification without Docker skips `real_docker` tests. Most lifecycle
and failure-path tests use a fake Docker CLI; they establish that model's
behavior, not every real isolation or cleanup boundary. The earlier real-daemon
demo and timeout/cancellation seeds cover their documented paths. The
[support matrix](https://github.com/cooneycw/skillc/blob/v0.5.0/docs/specs/evaluation-facility/support-matrix.md)
remains the authority for the scope of live evidence. Release preparation itself
adds no live daemon or model run.
