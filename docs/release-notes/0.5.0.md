# skillc 0.5.0 - controlled evaluation workflows and retained evidence

0.5.0 expands the evaluation facility beyond the 0.4.0 hardening release:
workflow dependency profiles, qualified task fixtures, calibration and uptake
studies, controller-held observations, fixture services and retained evidence
export. The static checker still proves its 31 rule families discriminate.
The complete change inventory is the
[tag-pinned changelog](https://github.com/cooneycw/skillc/blob/v0.5.0/CHANGELOG.md).

## What ships

- Profiles declare and close transitive workflow dependencies, preserve source
  executable modes, and select pinned runtime supplies. Agent egress is restricted
  to the declared provider; grading uses a separate network-none backend
  ([#343](https://github.com/cooneycw/skillc/issues/343),
  [#442](https://github.com/cooneycw/skillc/issues/442),
  [#538](https://github.com/cooneycw/skillc/issues/538), all closed).
- Qualified Level 3 fixtures exercise omitted tests, incomplete aggregate gates,
  and clean-project versus must-act decisions through a controller-owned fixture
  service and gate witness. Qualification checks the graders themselves, including
  wrong candidates and broken-grader controls
  ([#270](https://github.com/cooneycw/skillc/issues/270),
  [#434](https://github.com/cooneycw/skillc/issues/434), closed).
- Calibration and description uptake studies have retained live reports. The
  [two-arm calibration](https://github.com/cooneycw/skillc/blob/v0.5.0/evals/calibration-204/report.md)
  found both arms at ceiling (4/4 each), with no natural skill opening.
  [B/N/P calibration](https://github.com/cooneycw/skillc/blob/v0.5.0/evals/calibration-203/report.md)
  also reached ceiling; its nested-directory installation constraint is now
  documented alongside the results. The low-effort rerun remained at ceiling.
  [The uptake study](https://github.com/cooneycw/skillc/blob/v0.5.0/evals/uptake-study/README.md)
  measured a bounded selection change after rewriting one description
  ([#237](https://github.com/cooneycw/skillc/issues/237), closed).
- `skillc retained-export` supports no-spend reproduction and privacy-safe
  handoff of retained evidence. The delivered handoff preserves unknown
  installation readiness and overall INCONCLUSIVE results; a task endpoint PASS
  is not an overall verified PASS
  ([#556](https://github.com/cooneycw/skillc/issues/556), closed).
- Selection probes pin complete grader identities and store eligible real-adapter
  verified results; executable helpers keep their source classification. Historical
  evidence is unchanged. Whole [#545](https://github.com/cooneycw/skillc/issues/545)
  remains open for trusted-regrade and baseline-identity work.
- Release preparation now includes a clean built-wheel installation in both
  `make verify` and CI, followed by installed-rule, missing-controls and same-exit structured-findings
  sabotage controls. README selftest sample counts are checked against registered rules.

## Evidence boundaries and work still owed

A container gate with no Docker daemon skips `real_docker` tests. Most lifecycle
and failure-path tests use a fake Docker CLI. Those tests establish behavior
under that model; they do not establish real isolation, daemon cleanup or live
client compatibility for every path. The earlier real-daemon demo and
cancellation/timeout seeds remain bounded to their documented paths; the
[support matrix](https://github.com/cooneycw/skillc/blob/v0.5.0/docs/specs/evaluation-facility/support-matrix.md)
is the authority for the scope of live evidence. This release preparation adds
no live daemon or model run.
