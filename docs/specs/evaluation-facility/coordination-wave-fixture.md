# Trusted coordination quote task - independent phase P (#571)

This phase supplies a real local task service, frozen captures and a qualified
oracle through existing `verify.grade_files`. It does not execute a coordination
wave. The dependent attachment/API, genuine #569A delivery and a separately
approved implementation gate remain prerequisites. No native wake, agent/model
study, hostile same-UID isolation or production-timeout benefit is established.

The public goal combines two closed replace-file patches: worker A implements
`subtotal(qty, unit_cents)`, worker B implements round-half-up basis-point tax.
The seeded quote entrypoint calls both and returns subtotal, tax and total cents.
Quantity is one of 0,1,2,4; unit cents 0,1,7,123,199; basis points
0,500,1300,5000,10000. The full Cartesian product has exactly 100 inputs.
The trusted judge computes expected values independently with Decimal arithmetic.
For example, 2 units at199 with500 basis points gives398/20/418;1 at1 with5000
gives1/1/2. No behavior outside the frozen domain is certified.

`quote-task.json` freezes seed bytes, two valid implementations per worker and
the exact 16-case qualification population. A patch binds role, permitted source
path, seed-file digest and replacement content. The entire captured JSON patch,
including whitespace/metadata, and its canonical object are each limited to
4096 UTF-8 bytes. Workers never own Git
metadata. `quote_task.py` invokes fixed trusted patch producers and the closed
service transaction through existing owned trial attempts; this is fixture
qualification, not a second session engine. It captures their actual outputs
after confirmed stop, then revalidates manifests and objects before interpretation.

The service edits only its controller-created repository under neutral local-only
Git configuration. `refs/heads/delivered` is the authoritative delivered location.
It captures `fixture-remote.git` as ordinary fixture evidence without weakening
the `.git` exclusion. A claim file always says success, deliberately including
wrong/unfinished service modes. Claims are not trusted observations.

The read-only oracle adapter reconstructs verified captured files and uses the
existing safe Git snapshot reader, never post-stop host Git. It independently
reads delivered ref, tree, ancestry and actual source, checks both captured patch
identities and seed binding, and passes controller-held facts via
`trusted_observation`. The probe sees only the delivered source and public input
vectors. The trusted judge runs after the supervised probe has stopped. Missing
or corrupt captures are UNKNOWN; positively wrong delivered effects are FAIL.
Correct local files cannot rescue a wrong remote; wrong local files do not
invalidate an independently correct remote. Both implementation/order alternatives
must pass. The same captured tree supplies behavior and delivery evidence.
Trusted identity retains each tree entry's mode, object ID and observed kind.
Only regular blob entries are materialized as source, and the closed replace-file
contract preserves mode100644. Symlinks/gitlinks or unintended mode changes are
wrong delivery, not regular source. A readable snapshot with no delivered ref is
also wrong delivery; absent/unreadable snapshot evidence remains UNKNOWN.

`quote-grader.json` is an existing GraderDef descriptor staged as `grader.json`
in an owned temporary directory. Only the public domain projection is staged as
`inputs.json`; qualification expectations and reference implementations do not
enter probe inputs. Record the actual resolved grader digest and input identity,
not an assertion that the committed task declaration is the probe input file.

Qualification calls `quote_task.qualify(base)`. It rejects empty, missing, extra
or duplicate case selections before execution. Certification requires all16
observed statuses AND exact violated-criterion sets to match the declaration;
a crash is not an observed task failure. Thirteen cases reach the oracle; three
missing/corrupt-object cases stop at unavailable evidence. Retain planned,
executed and oracle-executed totals from the returned report (the fixture tests
persist both real and broken-grader reports). Exact expected fault activation,
oracle execution, on-time completion and confirmed cleanup must also match;
unrelated infrastructure loss cannot stand in for an injected corruption.
Required bad graders are always-pass,
always-fail, crash and no-output; each must refuse the real population. Input
population rejection is separately tested against healthy full qualification.

Each case plans three scripted diagnostic attempts, including a never-run
attempt on setup failure. Confirmed process stop, captures, derived lifecycles,
workspace cleanup and supervised verifier cleanup are required. These counts
are qualification diagnostics, not a wave denominator or a live measurement.
The future attachment will count exactly one planned wave as primary.

A case budget starts before its fixture setup. Remaining time bounds service
execution and admission to verification; final lateness is checked after cleanup.
The existing verifier sets probe and judge limits independently: this phase does
not claim an absolute no-new-launch-after-expiry boundary inside that function.
Pre-clipped phase limits are not proof of that stronger guarantee. The selected
shared-verifier prerequisite and its actual ownership/cleanup evidence must be
cleared before phase D promises that boundary. Host I/O is not forcibly
interruptible, and teardown grace never earns on-time credit. Final wave decision
publication is not implemented here; the accepted #569A completion-boundary and
fail-closed staging/replacement contract remains a phase D requirement.

All task interpretation remains in the fixture. No coordination core, shared
trial/backend/service/verifier, record schema, CLI or native transport is changed.
Later product-versus-comparator and old-versus-fixed comparisons need different
predeclared arms, exact shipped pins, matched resources, randomized order and
explicit live approval. A successful qualification cannot establish uplift.
